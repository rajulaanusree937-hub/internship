# Internship Repository

This repository combines four internship data projects into a single workspace for easy access, review, and presentation.

## Overview

The projects included here cover flight delay analysis, predictive modeling, dashboarding, and sentiment analysis across different datasets and tools.

## Project Index

- [Task 1: Big Data Flight Delay Analysis with PySpark](./task-1-big-data-flight-delay-analysis-pyspark/README.md)
- [Task 2: Predictive Analysis Using PySpark ML](./task_2_predictive_analysis_using_pyspark_ml/README.md)
- [Task 3: Flight Delay Dashboard](./task-3-flight-delay-dashboard/README.md)
- [Task 4: Sentiment Analysis](./task-4-sentiment-analysis/README.md)

## Included Tasks

### 1. Big Data Flight Delay Analysis with PySpark
This project analyzes flight delay data using PySpark to demonstrate big data processing, cleaning, and scalable analytical workflows.

### 2. Predictive Analysis Using PySpark ML
This project predicts flight delays using PySpark MLlib and machine learning techniques including preprocessing, feature engineering, and logistic regression.

### 3. Flight Delay Dashboard
This project creates an interactive Power BI dashboard to visualize flight data, delays, airline performance, and route trends.

### 4. Sentiment Analysis
This project performs sentiment analysis on Amazon review data using NLP techniques to classify reviews into positive, negative, and neutral categories.
